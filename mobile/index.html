Revisão Mobile — 7 componentes

Cada componente está renderizado em iframes 375 px (iPhone 12/13/14 base) e 768 px (limite tablet) lado a lado. Mexa nas iframes para validar interações.

Todos os arquivos JSX/CSS finais estão em /output/ prontos para colar no projeto (mantém todas as importações reais: react-router-dom, framer-motion, @tanstack/react-query, etc).

Breakpoint
960 → 768 px
Alinhado com md do Tailwind. Mobile entra abaixo de 768.
Tipografia
clamp() fluido
Títulos, parágrafos e captions escalam suavemente de 320 a 1440.
Touch targets
≥ 44 px
Hamburguer 42×42 (toque confortável), itens de menu mobile 44px+, paginação 44px+.
Hover effects
@media (hover: none)
Translate-on-hover desligado em touch — só active com scale leve.
Animações
Suavizadas
Parallax reduzido no Hero, desligado no CityHero. Canvas com 32 partículas (era 80). Framer Motion mantido.
Performance
backgroundAttachment
fixed → scroll no mobile (Apoie). Evita jank no iOS Safari.
01 — Navegação

Navbar

Breakpoint muda de 960 para 768. Hamburguer 42×42 com hit-target confortável. Menu mobile com itens 44px+, body-scroll-lock quando aberto, e barra opaca quando há scroll.

Arquivos atualizados

  • output/components/Navbar.jsx — breakpoint 768, body-scroll-lock, classes CSS extraídas, ARIA labels.
  • output/global.css — tokens fluidos --fs-*, helpers .podcast-floating-wrap, @media (hover: none).
Principais mudanças
  • Media query final passou de max-width: 960px para max-width: 767px
  • Adicionado useEffect que trava o scroll do body quando o menu mobile está aberto
  • Padding do .container-rota reduzido de 1.5rem para 1rem abaixo de 640px
  • Hit target do burger aumentou de 36×36 para 42×42, menu items de ~40px para 48px de altura
  • Itens com aria-label e aria-expanded para acessibilidade
02 — Topo

HeroSection

Coluna direita (cards de país + mapa + UNESCO) escondida abaixo de 768. Podcast vira mini-player flutuante no canto inferior direito após rolar 40% do hero. Parallax do scroll reduzido (de 90px → 40px). Lens flare encolhe. Canvas de partículas reduz de 80 para 32 partículas.

768Tablet / desktop ↑

Arquivos atualizados

  • output/components/HeroSection.jsx — useMediaQuery, mini-player flutuante, podcast extraído em componente reutilizável.
  • output/global.css — .hero-grid e .hero-right-col com breakpoint 768.
Principais mudanças
  • Coluna direita: display: none no mobile via .hero-right-col + media query 767px
  • Podcast extraído num componente <PodcastPlayer floating={isMobile}> reaproveitável
  • Mini-player flutuante aparece após scrollY > window.innerHeight * 0.4, com botão fechar persistente na sessão
  • Parallax: useTransform(scrollY, [0, 700], [0, isMobile ? 40 : 90])
  • Canvas mobile: 32 particles + 3 birds (era 80 / 7) — economia de bateria
  • Stats com clamp() e bordas com gap responsivo (clamp(10px, 3vw, 20px))
  • Tamanho das letras dos títulos: clamp(2.6rem, 11vw, 7.5rem) via token --fs-hero-title
03 — Destinos

CitiesSection

O sticky-scroll com o mapa de zonas clicáveis some no mobile (zonas viram pequenas demais para hit-targets). Em seu lugar: grid de cards por país — 1 coluna até 480px, 2 colunas de 481–767. Modal "pergaminho" mantida com tamanho responsivo. No desktop, comportamento original preservado.

Arquivos atualizados

  • output/components/CitiesSection.jsx — dois layouts (DesktopMap + MobileGrid) com switch via useMediaQuery.
Principais mudanças
  • Mobile (< 768): grid de 4 cards com foto da cidade-âncora de cada país, bandeira + nome do país + count de cidades + CTA
  • Tap no card abre o mesmo modal pergaminho com tamanho min(420px, 92vw)
  • Hit-target mínimo: card inteiro (aspect-ratio 4/5) — fácil de tocar
  • Sticky scroll de 220vh é eliminado no mobile — economia massiva de scroll
  • Atalhos de bandeira (linha de emojis) some no mobile, redundante com o grid
  • Desktop intocado: continua com image map + sticky scroll

ApoieSection

3 cards empilhados em 1 coluna. backgroundAttachment: fixed é desligado no mobile (quebra no iOS Safari + custa bateria) — vira scroll. Padding interno dos cards reduz de 32 para 26px, mantendo a hierarquia visual.

07 — Páginas de cidade

CityHero

Parallax desligado no mobile (scroll Y, mouse X, Ken Burns scale). Imagem fica fixa, performance recupera. Animações de entrada (nome, tagline, stats) mantidas mas com durations menores (0.8s em vez de 1.2s). Grid de stats: 2 cols até 480, auto-fit depois. Sticky scroll downstream preservado.
